## 每页检查项

1. 点击扩展图标显示约 320–360px 的 popup；支持页面显示 OJ、题号、标题和主按钮，不支持页面显示轻量提示。
2. popup 底部的“打开时间线”和“设置”可以打开或聚焦既有页面；时间线功能和同步状态不受影响。
3. 点击“直接导出 PDF”后原题页面保持不变，不创建或切换标签页；PDF 直接下载。下载完成或中断后不残留 offscreen document。关闭 popup 后本地导出继续；重新打开后再次触发不会并发导出。点击“编辑 / 预览后导出”才打开独立编辑页，初次加载只预览、不自动下载。
4. PDF 为 A4；标题下显示时间/内存限制；中文、日文或英文正文可读；标题层级、列表、表格、公式、代码块、样例和图片没有明显裁切。
5. 多页题面有页码；标题和样例不孤立落在页底；长代码可以换行；无法嵌入的图片保留替代文字和原图链接。
6. 在导出过程中切换活动标签页或改变原题 URL，任务应失败并提示重新发起，不应导出另一页内容。
7. 直接导出失败或超时应清理隐藏执行环境和下载监听，错误返回 popup，允许重新发起；编译超时的迟到结果不应下载文件。关闭编辑页或断开其交付端口后，后台采集应清理；重复使用过期 token 应失败。
8. 无题面、登录页、WAF/challenge 页和不支持站点不会误识别为可导出题目。
9. 生成 PDF 时按钮保持蓝色并显示旋转图标与「正在生成 PDF…」，鼠标为普通指针；长题面编译期间动画与底部导航仍能响应。编辑页预览与导出共用独立 Worker，关闭页面后应终止 Worker。
