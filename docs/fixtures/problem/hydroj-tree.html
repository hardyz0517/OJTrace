生成树很爽（tree）

题目描述

给定 $n,l$ 和 $m$ 个三元组 $(l_i, r_i, w_i)$。 定义 $G_k$ 为：

  • 新建一个 $n\times (k+1)$ 个点的图。
  • 对于每个三元组 visual tuple(l_i,r_i,w_i)visual tuple，在图上加入 visual kkvisual k 条边：
    • 第 $j$ 条边连接节点 $l_i + (j-1) \times n$ 和节点 $r_i+j\times n$，边权为 $w_i$。
  • 所有边加入完毕后，$G_k$ 即为该图最小生成树的边权和。

你要求出 $G_1\sim G_l$。给定的 $m$ 个三元组保证上述生成的所有图连通。

输入格式

第一行三个整数 $n,l,m$。

接下来 $m$ 行，每行一个三元组 $(l_i, r_i, w_i)$。

输出格式

依次输出 $G_1\sim G_l$。
