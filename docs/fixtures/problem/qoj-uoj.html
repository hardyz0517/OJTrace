给出一个 $N$ 行 $M$ 列的矩阵，保证 $M > N$。

输入格式

第一行一个正整数 $T$，表示数据组数。

输出格式

对于每组数据输出一行。如果有解，则输出 $N$ 个整数。

样例一

input

2
5 10

output

4 5 3 1 2

explanation

两组输入可以给出任意一组合法答案。
