# OJTrace v0.1.2

## 复用与维护升级

- 统一五个来源的静态 metadata、官网地址和固定 origin，新增来源时由穷尽注册与架构门禁发现遗漏。
- 洛谷/QOJ 复用窗口、页序、去重、进度和后续失败分类，同时保留各站分页证据与身份策略。
- 统一 Runtime 消息客户端、响应校验、公开回包脱敏、错误构造和授权输入边界。
- 复用 HTML 解码、请求目标校验、串行队列、可取消等待和测试 fixtures。
- 共享 AnimatedSelect 和页面基础样式，保留设置页/时间线的尺寸差异。
- 公开 `SYNC_RESULT.sources` 不再携带内部 `activitySchedules`；存储 schema 保持 2。

## 验证

- 598 个自动测试通过，1 个 opt-in live 测试按配置跳过。
- 276 个 adapter/domain contract 测试通过。
- typecheck、lint、format、build、manifest audit、architecture audit 通过。
- 应用内浏览器完成页面切换、下拉/日期/同步弹层、键盘交互和窄屏横向滚动验收。
- Chrome/Edge 真实扩展、权限、Cookie、登录态和重启持久化验收仍按 [浏览器矩阵](../qa/browser-matrix.md) 待完成；本 Release 说明不将模拟预览当作真实扩展验收。

安装方式：下载 Release 附件 `ojtrace-0.1.2-chrome.zip`，解压后在 Chrome/Edge 的扩展管理页以开发者模式加载包含 `manifest.json` 的目录。
