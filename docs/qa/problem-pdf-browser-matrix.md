## 每页检查项

1. 点击扩展图标显示约 320–360px 的 popup；支持页面显示 OJ、题号、标题和主按钮，不支持页面显示轻量提示。
2. popup 底部的“打开时间线”和“设置”可以打开或聚焦既有页面；时间线功能和同步状态不受影响。
3. 点击“导出题面 PDF”后原题页面保持不变，导出页显示状态并自动下载单题 PDF。
4. PDF 为 A4；标题下显示时间/内存限制；中文、日文或英文正文可读；标题层级、列表、表格、公式、代码块、样例和图片没有明显裁切。
5. 多页题面有页码；标题和样例不孤立落在页底；长代码可以换行；无法嵌入的图片保留替代文字和原图链接。
6. 在导出过程中切换活动标签页或改变原题 URL，任务应失败并提示重新发起，不应导出另一页内容。
7. 关闭导出页或断开端口后，后台任务应清理；重复使用过期 token 应失败。
8. 无题面、登录页、WAF/challenge 页和不支持站点不会误识别为可导出题目。
