# OJTrace v0.1.3

## 题面 PDF 导出

- 工具栏按钮改为 popup。在洛谷、Codeforces、AtCoder、QOJ、HydroOJ 的题面页识别题目，并导出一份单题 A4 PDF；原题页面保持不动。
- 题面在本地用 Typst 编译。字体、公式包和样例样式随扩展打包，失败时不再回退到 HTML 打印预览。
- Typst WASM 里少量 `new Function` 回调换成了等价的普通函数，扩展页 CSP 仍然禁止远程代码和 eval。
- 导出任务绑定发起时的标签页和 URL。任务过期、页面被关掉或地址变了之后，不能拿旧 token 再导出。
- 删掉没有引用的题面桶文件、图片像素解析和旧打印样式。存储 schema 保持 2。

## 验证

- 719 个自动测试通过，1 个 opt-in live 测试按配置跳过。
- 276 个 adapter/domain contract 测试通过。
- typecheck、lint、format、build、manifest audit、architecture audit 通过。
- Chrome/Edge 真实扩展加载、下载和 PDF 视觉验收仍按 [题面浏览器矩阵](../qa/problem-pdf-browser-matrix.md) 待完成；本 Release 说明不把自动化测试或已捕获页面的离线编译当作真实扩展验收。

安装方式：下载 Release 附件 `ojtrace-0.1.3-chrome.zip`，解压后在 Chrome/Edge 的扩展管理页以开发者模式加载包含 `manifest.json` 的目录。
